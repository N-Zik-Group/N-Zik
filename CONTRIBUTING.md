# 🤝 Contributing to N-Zik

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).



## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/N-Zik.git

## ✅ Verify your changes

Clone with submodules using `git clone -b main --single-branch --recursive https://github.com/N-Zik-Group/N-Zik.git`. Follow the README to create `release_notes.txt`, then run `./gradlew :ComposeN-Zik:assembleDebug` and the relevant unit tests. Verify UI changes on an emulator or device.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
