Androiderako YouTube Music bezero eleaniztuna: errendimendua, UI/UX, funtzioak eta epe luzeko laguntza.

<b>N-Zik</b> <a href="https://github.com/knighthat/Kreate">Kreate</a>-ren kode irekiko fork bat da.

<b>Oharra:</b> N-Zik hasi zen proiektu pertsonal gisa. Aukera helduagoak: <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> edo <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>AA erabilera:</b> AA sortzailea erabiltzen dut kodo, <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a> bidez; dena berrikusi eta probatua.

Entzule arrunta edo audiofiloa, N-Zik-ek zure musikaren kontrola ematen dizu, pribatutasun-kontzesiorik gabe.

✨ <b>ZERGATIK N-ZIK?</b> Iragarkirik gabe, atzeko erreprodukzioa, lineaz kanpoko cachea, interfaze pertsonalizagarria - doan, beti.

🎨 <b>Interfaze pertsonalizagarria</b>
- Jetpack Compose, ViMusic modu klasikoaren aldagailuarekin
- Gaiak: AMOLED, Deep Dark, Crisp Light + kolore-ukutuak
- 3D Carousel erreproduzitzailea, hasierako widgetak, erreproduzitzaile unifikatua
- Artisten profilak, aurkikuntzak eta "moods", goiburu tolestgarriak

🎵 <b>Audio esperientzia</b>
- Kalitate premiuma YouTube Music Premium bidez, automatikoa
- Letra sinkronizatuak, edizioa eta denbora errealeko itzulpena
- Abestiak ezagutzea (Shazam antzekoa), ahots-bilaketa, audio bisualizatzailea
- Kontrol profesionalak: abiadura, tonua, normalizazioa, crossfade-a, bolumena, baxua, erreburbu
- Audio Bar seekbara, navigazio zehatzeko

💾 <b>Lineaz kanpo, metadatuak eta pribatutasuna</b>
- Abesti eta zerrendentzako cache adimentsua, deskargak kalitate aukeragarriz
- FFmpeg esportazioa metadatu osoekin (64-bit soilik)
- Metadatuen editorea aplikazioan (AAC/Opus, azala)
- Entzute-estatistikak eta historia lokalak
- Babeskopia automatikoa, tarte eta mantentze pertsonalizatuak

🔗 <b>Integrazioak</b>

📦 <b>Bertsio eskuragarriak</b>
- Full/Beta: Bertsio osoa (64-bit)
- Full32/Beta32: FFmpeg gabe (32/64-bit)
- Minified: Arina, gama baxuko gailuentzat (64-bit)
- Minified32: Arina FFmpeg gabe (32/64-bit)
- FOSS: Eguneratzaile automatikorik gabe, F-Droid-erako (64-bit)
- Dev/Dev32: Garapen bertsioak, probetarako soilik

Bertsio estandarrak 64-bit (FFmpeg); "32" bertsioak FFmpeg kentzen dute bi arkitekturetan. FOSS soilik dago F-Droid-en.
