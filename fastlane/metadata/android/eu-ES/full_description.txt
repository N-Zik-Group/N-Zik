<b>N-Zik</b> zure YouTube Music bezero eleaniztun eta kode irekiko Androiderako.

<a href="https://github.com/knighthat/Kreate">Kreate</a>-ren fork bat, errendimenduan, interfazearen hobekuntzan, akatsen konponketan eta epe luzerako laguntzan zentratua.

<b>Oharra:</b> N-Zik proiektu pertsonal gisa hasi zen. Aukera helduagoak ikusteko, begiratu <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> edo <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>AA erabilera:</b> AA sortzailea erabiltzen dut koderako (<a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD metodoa</a>), dena berrikusi eta probatu egiten da argitaratu aurretik.

Entzule arrunta edo audiofiloa izan, N-Zik-ek zure musikaren gaineko kontrol osoa ematen dizu pribatutasuna arriskuan jarri gabe.

✨ <b>ZERGATIK N-ZIK?</b> Iragarkirik gabe, atzeko planoko erreprodukzioa, lineaz kanpoko cachea eta interfaze pertsonalizagarria; doan, beti.

🎨 <b>Interfaze pertsonalizagarria</b>
- Jetpack Compose ViMusic modu klasikoarekin
- Gaiak: AMOLED, Deep Dark, Crisp Light + kolore-ukutuak
- 3D Carousel erreproduzitzailea, hasierako pantailako widget pertsonalizagarriak
- Artisten profilak, albisteen jarioa, widget esperimentalak

🎵 <b>Audio esperientzia</b>
- Kalitate handiko audioa YouTube Music Premium bidez (Web Remix)
- Letra sinkronizatuak edizioarekin eta denbora errealeko itzulpenarekin
- Denbora errealeko audio bisualizatzailea eta kontrol profesionalak: abiadura, tonua, normalizazioa, crossfade-a, bolumen indartzea

💾 <b>Lineaz kanpo, metadatuak eta pribatutasuna</b>
- Lineaz kanpoko cache adimentsua eta deskargak abesti eta erreprodukzio-zerrendentzat
- FFmpeg bidezko esportazioa metadatu osoekin (64 bitekoak soilik)
- Metadatuen editorea aplikazioan (AAC/Opus, azala)
- Entzute estatistikak eta historia %100 lokalean
- Babeskopia automatikoa tarte eta mantentze pertsonalizatuekin

🔗 <b>Integrazioak</b>
- YouTube saio-hasiera gomendioak eta audio/bideo aldaketarako
- Discord Rich Presence
- Erreprodukzio-zerrenden inportazioa/esportazioa: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Erreproduzitu edonon:</b> Android Auto, Automotive, TV eta tabletak

🛠️ <b>Funtzio aurreratuak</b>
- Testu eta ahots bidezko bilaketa
- GitHub bidezko OTA eguneratzeak
- Lo-tenporizadorea eta atzeko planoko erreprodukzioa

🛡️ %100 kode irekikoa (FOSS). Baimen nagusiak: INTERNET, RECORD_AUDIO (bisualizatzailerako soilik), STORAGE (esportazioak/babeskopiak), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Bertsio eskuragarriak</b>
- Full/Beta: Bertsio osoa (64 bitekoak soilik)
- Full32/Beta32: FFmpeg gabe (32/64 bitekoak)
- Minified: Arina, gama baxuko gailuentzat (64 bitekoak soilik)
- Minified32: Arina FFmpeg gabe (32/64 bitekoak)
- FOSS: Eguneratzaile automatikorik gabe, F-Droid-erako (64 bitekoak soilik)
- Dev/Dev32: Garapen bertsioak, probetarako soilik

Bertsio estandarrak 64 bitekoak dira (FFmpeg); „32" bertsioek FFmpeg kentzen dute bi arkitekturetan. FOSS soilik dago F-Droid-en.
