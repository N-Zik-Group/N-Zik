YouTube Musiceko frontenda, hainbat hizkuntzan, Androiderako: errendimendua, UI/UX, funtzio hedapena, epe luzeko babesa.

<b>N-Zik</b> <a href="https://github.com/knighthat/Kreate">Kreate</a>-ren iturburu irekiko fork bat da.

<b>Oharra:</b> N-Zik alde-proiektu gisa hasi zen. Alternatiba helduagoak: <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> edo <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>AI erabilera:</b> AI generatiboa erabiltzen dut kodetarako (<a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a> bidez), aurretik aztertu eta probatuta.

Entzule arrunta edo audiophile, N-Zik-ek musikaren kontrol osoa ematen dizu, pribatutasuna kaltetatu gabe.

✨ <b>Zergatik N-ZIK?</b> Iragarkirik gabe, hondo-erreprodukzioa, cache offline, UI pertsonalizagarria - doan, beti.

🎨 <b>UI pertsonalizagarria</b>
- Jetpack Compose, ViMusic modu klasikoaren toggle
- Gaiak: AMOLED, Deep Dark, Crisp Light + akzentu tonatuak
- 3D Carousel Player, hasierako widgetak, jokalari + mini-jokalari bateratuak
- Artista profilak, Discovery eta moodak, hasierako goiburu ezkutagarriak

🎵 <b>Soinu-esperientzia</b>
- Kalitate premiuma YouTube Music Premium bidez, automatikoki
- Letrak sinkronizatuak, editatzea eta denbora errealeko itzulpena
- Abesti-errekonoztea (Shazam bezala), ahots-bilaketa, soinu-visualizagailua
- Pro kontrolak: abiadura, tonua, normalizazioa, crossfade, bolumen- eta baxu-igoera, reverb
- Audio Bar uhin-seekbar, navigazio zehatzarako

💾 <b>Offline, metadatuak eta pribatutasuna</b>
- Pisten eta playlisten cache adimenduna, deskargak aukeragarriko kalitatez
- FFmpeg bidezko esportazioa, metadatu osoekin (64-bit bakarrik)
- Metadatu editorea aplikazioan (AAC/Opus, azal-arteak)
- Entzute-estatistikak eta historia lokalak
- Babeskopia automatikoa, tarteen eta mantentzeen arabera

🔗 <b>Integrazioak</b>
- YouTube sarrera gomendio eta bideo-erreprodukziorako, bi noranzkoko sinkronizazio-motor esperimentala
- Last.fm scrobbling, Now Playing eta love/unlove
- MusicBrainz artisten eta albumen informazioa
- Discord Rich Presence, modu aurreratua eta aurrebista bizia
- Invidious, YouTube streaming alternatiborako
- Playlisten inportazio/esportazioa: RiPlay, Spotify, YouTube Music, N-Zik

👥 <b>Bateran entzutea</b>
- Saio bizian parte hartu edo antolatu beste erabiltzaileekin, kodetik edo gonbidapen-estekatik

🗓️ <b>Rewind</b>
- Urteko eta hilabeteroko laburpenak, auto-sortutako Rewind playlistak

📱 <b>Non-erron erreproduzitu:</b> Android Auto, Automotive, TV eta Tablets

🛠️ <b>Erabiltzaile aurreratuentzat</b>
- Profil anitzak: datu-base eta ezarpen bananduak profil bakoitzeko
- Bluetooth konektatzean berrabiarazte automatikoa, ilara iraunkorra, auto-betearaztea
- Zurrunbilo adimenduna, euskatutako abestiak, ez gustuko sistema, guraso-kontrola
- Proxy euskarria, sare-kalitate egokitzapena, erregistro-esportazioa

🛡️ 100% iturburu irekia (FOSS). Baimenak: INTERNET, RECORD_AUDIO (visualizagailurako), STORAGE (esportazio/kopia), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.
