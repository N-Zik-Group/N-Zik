Многоязычный клиент YouTube Music для Android: быстродействие, удобный интерфейс, новые функции и долгосрочная поддержка.

<b>N-Zik</b> — форк <a href="https://github.com/knighthat/Kreate">Kreate</a> с открытым кодом.

<b>Примечание:</b> N-Zik начался как побочный проект. Более зрелые альтернативы: <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> или <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>ИИ:</b> Пишу код с генеративным ИИ по <a href="https://github.com/bmad-code-org/BMAD-METHOD">методу BMAD</a>. Проверяю и тестирую его перед выпуском.

✨ <b>ПОЧЕМУ N-ZIK?</b> Без рекламы, фоновое воспроизведение, офлайн-кеш, настраиваемый интерфейс - бесплатно, всегда.

🎨 <b>Настраиваемый интерфейс</b>
- Jetpack Compose интерфейс
- Темы: AMOLED, Deep Dark, Crisp Light + цветные акценты
- 3D Carousel Player, виджеты главного экрана, единый плеер и мини-плеер
- Профили исполнителей, Discovery и настроения, сворачиваемые заголовки

🫧 <b>Glass (BETA, по желанию)</b>
По умолчанию выключен. В настройках выберите по категориям обычный вид, контур или Glass и задайте качество. Если эффект нагружает устройство или батарею, снизьте качество или отключите его.
Авторы Glass: Square / Convx Project (GPL-3.0); Kyant0 AndroidLiquidGlass / Backdrop (Apache-2.0).

🎵 <b>Качество звука</b>
- Премиум-качество через YouTube Music Premium, применяется автоматически
- Синхронизированные тексты с редактированием и переводом в реальном времени
- Распознавание музыки (как Shazam), голосовой поиск, визуализатор
- Про-настройки: скорость, высота тона, нормализация, кроссфейд, усиление громкости, буст басов, реверберация
- Audio Bar с волновой шкалой для навигации

💾 <b>Офлайн, метаданные и приватность</b>
- Умный кеш и загрузка треков и плейлистов, с выбором качества
- Экспорт FFmpeg с полными метаданными (кроме 32-битных x86)
- Редактор метаданных в приложении (AAC/Opus, обложка)
- Локальная статистика и история прослушиваний
- Автобэкап с настраиваемыми интервалами и хранением

🔗 <b>Интеграции</b>
- Вход в YouTube для рекомендаций и видео, плюс экспериментальный двусторонний движок синхронизации
- Scrobbling Last.fm с Now Playing и love/unlove
- Профили исполнителей и альбомы MusicBrainz
- Discord Rich Presence, включая продвинутый режим с живым предпросмотром
- Интеграция Invidious для альтернативного YouTube-стриминга
- Импорт/экспорт плейлистов: RiPlay, Spotify, YouTube Music, N-Zik

👥 <b>Слушайте вместе</b>
- Подключайтесь к совместному прослушиванию или создавайте сеансы по коду или ссылке

🗓️ <b>Rewind</b>
- Годовые и месячные обзоры прослушивания с автогенерируемыми плейлистами Rewind

📱 <b>Слушайте где угодно:</b> Android Auto, Automotive, TV и Tablets

🛠️ <b>Функции для продвинутых</b>
- Многопрофильность: изолированная БД и настройки
- Автовозобновление при подключении Bluetooth, постоянная очередь, автозаполнение
- Умная корзина, скрытые песни, дизлайки, родительский контроль
- Поддержка прокси, адаптация качества сети, экспорт логов
- Rescue Center, экран обслуживания, онбординг, ярлыки приложения
- OTA-обновления с GitHub, таймер сна, фоновое воспроизведение

📦 <b>Доступные сборки</b>
- Release64/Beta64 (`com.nevar.nzik`): Полная сборка, только 64-битовые устройства
- Release32/Beta32 (`com.nevar.nzik`): Полная сборка, только 32-битовые устройства
- Minified64 (`com.nevar.nzik`): Облегчённая сборка R8, для слабых устройств (64-бит)
- Minified32 (`com.nevar.nzik`): Облегчённая сборка R8 (32-бит)
- FOSS (`com.nevar.nzik.foss`): Без автообновления, для F-Droid (все архитектуры)
- Dev64/Dev32 (`com.nevar.nzik.dev`): Для разработчиков, только для тестирования

FFmpeg не входит в сборки. Он скачивается при первом использовании. Управление: Настройки → Расширения. На F-Droid есть только FOSS.

Исторические кредиты проекта включают ViMusic.
