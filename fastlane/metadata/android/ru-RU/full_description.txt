<b>N-Zik</b> — ваш многоязычный клиент YouTube Music для Android с открытым исходным кодом.

Форк <a href="https://github.com/knighthat/Kreate">Kreate</a>, ориентированный на производительность, улучшение интерфейса, исправление ошибок и долгосрочную поддержку.

<b>Примечание:</b> N-Zik начался как побочный проект. Для более зрелых решений обратите внимание на <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> или <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Использование ИИ:</b> Я использую генеративный ИИ для написания кода (через <a href="https://github.com/bmad-code-org/BMAD-METHOD">метод BMAD</a>), всё проверяется и тестируется перед выпуском.

Будь вы обычным слушателем или аудиофилом, N-Zik даёт вам полный контроль над музыкой без ущерба конфиденциальности.

✨ <b>ПОЧЕМУ N-ZIK?</b> Без рекламы, фоновое воспроизведение, офлайн-кеш и полностью настраиваемый интерфейс — бесплатно, всегда.

🎨 <b>Настраиваемый интерфейс</b>
- Jetpack Compose с переключателем классического режима ViMusic
- Темы: AMOLED, Deep Dark, Crisp Light + цветные акценты
- 3D Carousel Player и настраиваемые виджеты на главном экране
- Профили исполнителей, лента новостей и экспериментальные виджеты

🎵 <b>Качество звука</b>
- Премиум-звук через YouTube Music Premium (Web Remix)
- Синхронизированные тексты с редактированием и переводом в реальном времени
- Аудиовизуализатор и профессиональные настройки: скорость, высота тона, нормализация, кроссфейд, усиление громкости

💾 <b>Офлайн, метаданные и конфиденциальность</b>
- Умное офлайн-кешивание и загрузка треков и плейлистов
- Экспорт через FFmpeg с полными метаданными (только 64-бит)
- Редактор метаданных в приложении (AAC/Opus, обложка)
- Локальная статистика и история прослушиваний
- Автоматическое резервное копирование с настраиваемыми интервалами

🔗 <b>Интеграции</b>
- Вход в YouTube для рекомендаций и переключения аудио/видео
- Discord Rich Presence
- Импорт/экспорт плейлистов: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Слушайте где угодно:</b> Android Auto, Automotive, TV и планшеты

🛠️ <b>Функции для продвинутых пользователей</b>
- Текстовый и голосовой поиск
- OTA-обновления через GitHub
- Таймер сна и фоновое воспроизведение

🛡️ N-Zik на 100% открыт (FOSS). Основные разрешения: ИНТЕРНЕТ, RECORD_AUDIO (только визуализатор), ПАМЯТЬ (экспорт/бэкапы), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Доступные сборки</b>
- Full/Beta: Полная (64-бит)
- Full32/Beta32: Без FFmpeg (32/64-бит)
- Minified: Облегчённая для слабых устройств (64-бит)
- Minified32: Облегчённая без FFmpeg (32/64-бит)
- FOSS: Без автообновления, для F-Droid (64-бит)
- Dev/Dev32: Сборки для разработчиков, только для тестирования

Стандартные сборки 64-битные (с FFmpeg); в сборках «32» FFmpeg удалён. Только FOSS доступна в F-Droid.

Начиная с <b>января 2027</b> Google потребует подтверждения личности от всех разработчиков. Как проект FOSS, N-Zik выступает против этого. <a href="https://keepandroidopen.org">Узнать больше</a> · <a href="https://www.change.org/p/stop-google-from-limiting-apk-file-usage/">Подписать петицию</a>
