Android üçün çoxdilli YouTube Music frontend proqramı: performans, UI/UX, geniş funksionallıq və uzunmüddətli dəstək.

<b>N-Zik</b> <a href="https://github.com/knighthat/Kreate">Kreate</a>-ın açıq mənbəli şaxəsidir.

<b>Qeyd:</b> N-Zik yan layihə kimi başladı. Daha yetkin alternativlər üçün <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> və ya <a href="https://github.com/fast4x/RiPlay">RiPlay</a>-ə baxın.

<b>Süni intellektin istifadəsi:</b> Kod üçün generativ süni intellektdən istifadə edirəm (<a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a>); kod yayımlanmazdan əvvəl yoxlanıb və test edilib.

Sadə dinləyici və ya audiofil: N-Zik məxfiliyinizi qoruyaraq musiqiniz üzərində tam nəzarət verir.

✨ <b>NİYƏ N-ZIK?</b> Reklamsız, arxa planda oxutma, oflayn keşləmə, fərdiləşdirilə bilən UI - həmişə pulsuz.

🎨 <b>Fərdiləşdirilə bilən UI</b>
- Temalar: AMOLED, Deep Dark, Crisp Light + rəngli aksentlər
- 3D Carousel Player, ana ekran widgetləri, birləşdirilmiş pleyer və mini pleyer
- Musiqiçilərin profilləri, Kəşf və moodlar, qatlanabilən ana ekran başlıqları

🎵 <b>Audio təcrübəsi</b>
- Premium keyfiyyət (YouTube Music Premium), avtomatik tətbiq olunur
- Redaktə və real vaxt tərcüməsi ilə sinxron sözlər
- Mahnı tanıma (Shazam kimi), səsli axtarış, audio vizuallaşdırıcı
- Pro idarəetmələr: sürət, ton, normallaşdırma, crossfade, səs artırma, bas gücləndirməsi, reverb
- Dəqiq navigasiya üçün Audio Bar dalğa forması zolağı

💾 <b>Oflayn, metaməlumatlar və məxfilik</b>
- Treklər və pleylistlər üçün ağıllı keşləmə və yükləmə, seçimli keyfiyyətlə
- Tam metaməlumatlarla FFmpeg ixracı (yalnız standart buildlər)
- Tətbiqdaxili metaməlumat redaktoru (AAC/Opus, albom qabığı)
- Yerli dinləmə statistikası və tarixçə
- Xüsusi intervallı və saxlanma müddətli avtomatik ehtiyat nüsxəsi

🔗 <b>İnteqrasiyalar</b>
- YouTube girişi: tövsiyələr, video oxutma, eksperimental iki istiqamətli sinxronlaşdırma mexanizmi
- Last.fm skroblinqi: Now Playing və love/unlove
- MusicBrainz musiqiçi və albom məlumatları
- Discord Rich Presence, canlı önizləməli mürəkkəb modus daxil
- Alternativ YouTube axını üçün Invidious
- Pleylist idxalı/ixracı: RiPlay, Spotify, YouTube Music, N-Zik

👥 <b>Birgə dinləyin</b>
- Canlı dinləmə sessiyasına kod və ya dəvət bağlantısı ilə qoşulun və ya başqaları ilə sessiya yaradın

🗓️ <b>Rewind</b>
- İllik və aylıq dinləmə xülasələri, avtomatik Rewind pleylistləri ilə

📱 <b>Hər yerdə oxudun:</b> Android Auto, Automotive, TV və Tablets

🛠️ <b>Peşəkar istifadəçi funksiyaları</b>
- Çox profil: hər profil üçün ayrıca verilənlər bazası və parametrlər
- Bluetooth qoşulanda avtomatik davam, daimi növbə, avtomatik doldurulma
- Ağıllı zibil, gizli mahnılar, bəyənməmə sistemi, valideyn nəzarəti
- Proksi dəstəyi, şəbəkə keyfiyyətinə uyğunlaşma, jurnal ixracı
- Rescue Center, baxım ekranı, onboarding, tətbiq qısayolları
- GitHub-dan OTA yeniləmələri, yuxu taymeri, arxa planda oxutma

📦 <b>Mövcud buildlər</b>
- Release64/Beta64 (`com.nevar.nzik`): Tam build, yalnız 64-bit cihazlar
- Release32/Beta32 (`com.nevar.nzik`): Tam build, yalnız 32-bit cihazlar
- Minified64 (`com.nevar.nzik`): Yüngül R8 build, zəif cihazlar üçün (64-bit)
- Minified32 (`com.nevar.nzik`): Yüngül R8 build (32-bit)
- FOSS (`com.nevar.nzik.foss`): Avtomatik yeniləyicisiz, F-Droid üçün (bütün arxitekturalar)
- Dev64/Dev32 (`com.nevar.nzik.dev`): İnkişaf buildləri, yalnız sınaq üçün

Heç bir build FFmpeg daxil etmir: bu, yüklənə bilən bir əlavədir (ilk istifadədə quraşdırılır, Tənzimləmələr → Əlavələr vasitəsilə idarə olunur). Yalnız FOSS F-Droid-dədir.
