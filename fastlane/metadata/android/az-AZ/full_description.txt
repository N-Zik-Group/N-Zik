<b>N-Zik</b> Android üçün açıq mənbəli, çoxdilli YouTube Music müştərinizdir.

<a href="https://github.com/knighthat/Kreate">Kreate</a>-in performans, UI təkmilləşdirilməsi, xəta düzəlişləri və uzunmüddətli dəstək yönəlmiş bir qoludur.

<b>Qeyd:</b> N-Zik yan layihə kimi başladı. Daha yetkin seçimlər üçün <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> və ya <a href="https://github.com/fast4x/RiPlay">RiPlay</a>-ə baxın.

<b>Süni intellekt istifadəsi:</b> Kod üçün generativ süni intellektdən istifadə edirəm (<a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Metodu</a> vasitəsilə), hər şey təqdim etməzdən əvvəl nəzərdən keçirilir və yoxlanılır.

İstər sadə dinləyici, istərsə də audiofil olun, N-Zik məxfiliyinə xələl gətirmədən musiqiniz üzərində tam nəzarət verir.

✨ <b>NİYƏ N-ZIK?</b> Reklam yoxdur, arxa fon oynatma, oflayn keşləmə və fərdiləşdirilə bilən interfeys — həmişə pulsuzdur.

🎨 <b>Fərdiləşdirilə bilən UI</b>
- Klassik ViMusic rejimi keçidi ilə Jetpack Compose
- Temalar: True AMOLED, Deep Dark, Crisp Light və rəngli vurğular
- 3D Karusel Pleyeri və ana ekran vidjetləri
- Sənətçi profilləri, Xəbər Lenti və eksperimental vidjetlər

🎵 <b>Audio Təcrübəsi</b>
- YouTube Music Premium  vasitəsilə premium keyfiyyətli audio
- Redaktə və real vaxt tərcüməsi ilə sinxronlaşdırılmış mahnı sözləri
- Real vaxt audio vizuallaşdırıcısı və peşəkar idarəetmələr: sürət, ton, normallaşdırma, crossfade, səs artırma, reverberasiya, bas gücləndirmə, musiqi tanıma (Shazam tipli), səsli axtarış

💾 <b>Oflayn, Meta Məlumatlar və Məxfilik</b>
- Treklər və pleylistlər üçün ağıllı oflayn keşləmə və yükləmələr
- Tam meta məlumatlarla FFmpeg ixracı (yalnız 64 bit)
- Tətbiqdaxili meta məlumat redaktoru (AAC/Opus, üz qabığı)
- Yerli dinləmə statistikası və tarixçəsi
- Xüsusi intervallarla avtomatik ehtiyat nüsxələmə

🔗 <b>İnteqrasiyalar</b>
- Tövsiyələr və audio/video keçidi üçün YouTube girişi
- Açıq mənbəli məzmun üçün Invidious
- Discord Rich Presence
- Pleylist idxalı/ixracı: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Hər yerdə dinləyin:</b> Android Auto, Automotive, TV və Planşetlər

🛠️ <b>Peşəkar Funksiyalar</b>
- Mətn və səsli axtarış
- GitHub-dan OTA yeniləmələri
- Yuxu taymeri və arxa fonda oynatma
- Bluetooth ilə avtomatik bərpa, davamlı növbə, avtomatik doldurma, ağıllı zibil, gizli mahnılar, valideyn nəzarəti, albom qapağından divar kağızı, Invidious, proksi, şəbəkə uyğunlaşması

🛡️ 100% açıq mənbəli (FOSS). Əsas icazələr: INTERNET, RECORD_AUDIO (yalnız vizuallaşdırıcı), STORAGE, FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Mövcud Versiyalar</b>
- Full/Beta: Tam versiya (yalnız 64 bit)
- Full32/Beta32: FFmpeg olmadan (32 və 64 bit)
- Minified: Yüngül, aşağı səviyyəli cihazlar üçün (yalnız 64 bit)
- Minified32: FFmpeg olmadan yüngül (32 və 64 bit)
- FOSS: Avtomatik yeniləyicisiz, F-Droid üçün (yalnız 64 bit)
- Dev/Dev32: İnkişaf versiyaları, yalnız sınaq üçün

Standart versiyalar 64 bitdir (FFmpeg daxil); "32" versiyalar hər iki arxitekturada işləmək üçün FFmpeg-i çıxarır. Yalnız FOSS F-Droid-dədir.
