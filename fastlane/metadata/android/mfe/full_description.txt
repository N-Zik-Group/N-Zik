Enn frontend YouTube Music multiling pou Android, ki fok lor performans, rafinman UI/UX, agrandisman fonksyon ek swivi long-lerm.

<b>N-Zik</b> se enn fork open-source de <a href="https://github.com/knighthat/Kreate">Kreate</a>.

<b>Nouet:</b> N-Zik ti koumans kouma enn proze kote. Pou le zot opsyon pli mature, verifie <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> ouswa <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Utilizasion IA:</b> Mo servi IA jenaratif pou kod (via <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a>), ki revize ek teste avan livrezon.

Si to enn senp lekouter ouswa enn audiophile, N-Zik donn to kontrol koupe lor to mizik, san konpromet to konfidansyalite.

✨ <b>KIFER N-ZIK?</b> Pa piblisite, lekout an bann, kaching offline, interfass ki to kapav kastomize - gratis, toultan.

🎨 <b>Interfass Kastomizab</b>
- Jetpack Compose avek enn basil pou mod ViMusic Klasik
- Tem: AMOLED, Deep Dark, Crisp Light + bann aksan kouloure
- 3D Carousel Player, widget pou lakaz, player inifie ek mini-player
- Profil artis, Discovery ek mood, tet lakaz ki kapav pliye

🎵 <b>Eksperians Audio</b>
- Kalite premium via YouTube Music Premium, ki aplik otomatikman
- Parol ki sinkronize, avek edision ek tradiksion an tan real
- Rekonesans mizik (kom Shazam), serch par lavwa, vizualizater audio
- Kontrol pro: vites, pitch, normalizasion, crossfade, boost volim, boost bas, reverb
- Audio Bar avek seekbar waveform pou navigasion presize

💾 <b>Offline, Metadone ek Konfidansyalite</b>
- Kaching zintel ek download pou morsò ek playlist, avek kalite download ki to kapav swazir
- Eksportasion avek FFmpeg ek metadone koupe (bann build standar selman)
- Editer metadone dan l'app (AAC/Opus, cover art)
- Statistik lekout ek l'istwar, tou lokal
- Back-up otomatik avek interval ek retansyon kastomizab

🔗 <b>Integrasion</b>
- Sign-in YouTube pou rekomandasion ek zwe video, plis enn motè sink dwouryon eksperimental
- Scrobbling Last.fm avek Now Playing ek love/unlove
- MusicBrainz pou plis detay lor artis ek album
- Discord Rich Presence, avek mod avanse ek preview an dirèk
- Integrasion Invidious pou streaming YouTube alternatir
- Import/eksport playlist: RiPlay, Spotify, YouTube Music, N-Zik

👥 <b>Lekout Ansam</b>
- Zwenn ouswa host enn sesion lekout an dirèk avek lot itilizater, par enn kod ouswa enn lien invitasion

🗓️ <b>Rewind</b>
- Rekòman lekout lor lane ek lor mwa, avek bann playlist Rewind ki kreye otomatikman

📱 <b>Jwe Partou:</b> Android Auto, Automotive, TV ek Tablets

🛠️ <b>Fonksyonalite Pou Power User</b>
- Multi-profils: baz done ek paramèt separe par profil
- Reprise otomatik lor koneksion Bluetooth, file persistan, file ki ranpli otomatik
- Poubel zintel, morsò kaché, sistèm dislike, kontrol parantral
- Sipor proxy, adaptasion kalite rezo, eksportasion log
- Rescue Center, ekran mantenans, onboarding, shortcut app
- Update OTA depi GitHub, timer pou dòmi, lekout an bann

📦 <b>Bann Build Disponib</b>
- Release64/Beta64 (`com.nevar.nzik`): Build koupe, 64-bit aparé selman
- Release32/Beta32 (`com.nevar.nzik`): Build koupe, 32-bit aparé selman
- Minified64 (`com.nevar.nzik`): R8 build leze, pou bann aparé molè (64-bit)
- Minified32 (`com.nevar.nzik`): R8 build leze (32-bit)
- FOSS (`com.nevar.nzik.foss`): San auto-updater, pou F-Droid (tous arsitektir)
- Dev64/Dev32 (`com.nevar.nzik.dev`): Bann build devlopman, pou test selman

Bann build pa kontann FFmpeg : sa enn ekstansyon téléchargeable (instal lor premie servi, gesti dan Paramèt → Ekstansyon). Se build FOSS selman ki lor F-Droid.
