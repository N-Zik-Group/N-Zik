<b>N-Zik</b> se enn klian YouTube Music open-source ek multiling pou Android.

Enn fork de <a href="https://github.com/knighthat/Kreate">Kreate</a> ki fokus lor performans, polissage UI, reparasion bann bug ek sipor alon-term.

<b>Nouet:</b> N-Zik ti koumans kouma enn proze personel. Pou lezot bon opsyon, ginn <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a>, ouswa <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Lirilizasion IA:</b> Mo servi IA generatif pou ed avek bann kod (atraver <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a>). Tou gagne revize ek teste avan larg.

Ki to sinp skouter ouswa vre fane mizik, N-Zik donn twa kontrol absoli lor to mizik san konpromet to konfidansialite.

✨ <b>KIFER N-ZIK?</b> Pa piblisite, lekout an background, kaching offline ek interfass kastomize — gratis, toultan.

🎨 <b>Interfass Kastomizab</b>
- Jetpack Compose avek bouton pou mod ViMusic Klasik
- Tem kastomize: AMOLED, Deep Dark, Crisp Light + bann kouler accent
- Player karousel 3D, widget home ki to kapav kastomize
- Profil artis, News Feed, widget eksperimantal

🎵 <b>Eksperians Audio</b>
- Audio kalite premium atraver YouTube Music Premium (Web Remix)
- Parol sanson sinkronize avek edite ek tradiksion tan real
- Vizualizater audio ek bann kontrol pro: vitess, pitch, normalizasion, crossfade, ogmantasion volim

💾 <b>Offline, Metadonne ek Konfidansialite</b>
- Kaching offline intelizan ek download pou morso ek playlist
- Eksportasion FFmpeg avek bann metadonne konple (64-bit selman)
- Editer metadonne dan l'app (AAC/Opus, cover art)
- Statistik lekout ek l'istwar 100% lokal
- Back-up otomatik avek bann interval ek retansion kastomize

🔗 <b>Integrasion</b>
- Sign-in YouTube pou rekomandasion ek sanzman audio/video
- Discord Rich Presence
- Inport/eksport playlist: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Zwe Partou:</b> Android Auto, Automotive, TV ek Tablet

🛠️ <b>Fonsionnalite Power User</b>
- Serch par teks ouswa lavwa
- Update OTA depi GitHub
- Timer pou somer ek lekout an background

🛡️ 100% open-source (FOSS). Bann permision kle: INTERNET, RECORD_AUDIO (pou vizualizater selman), STORAGE (eksport/backup), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Bann Build Disponib</b>
- Full/Beta: Build konple (64-bit selman)
- Full32/Beta32: San FFmpeg (32/64-bit)
- Minified: Build leze, pou bann masinn ki pa tro for (64-bit selman)
- Minified32: Build leze san FFmpeg (32/64-bit)
- FOSS: San auto-updater, pou F-Droid (64-bit selman)
- Dev/Dev32: Bann build devlopman, pou test selman

Bann build standar se 64-bit (avek FFmpeg); bann build "32" pa FFmpeg pou tou le de arkitektir. Selman build FOSS ki lor F-Droid.
