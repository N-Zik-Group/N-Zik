<b>N-Zik</b> adalah klien YouTube Music sumber terbuka multibahasa untuk Android.

Fork dari <a href="https://github.com/knighthat/Kreate">Kreate</a> yang berfokus pada performa, polesan UI, perbaikan bug, dan dukungan jangka panjang.

<b>Catatan:</b> N-Zik dimulai sebagai proyek sampingan. Untuk alternatif yang lebih matang, lihat <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a>, atau <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Penggunaan AI:</b> Saya menggunakan AI generatif untuk kode (melalui <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a>), ditinjau dan diuji sebelum dirilis.

Baik pendengar kasual maupun audiofil, N-Zik memberi Anda kendali penuh atas musik tanpa mengorbankan privasi.

✨ <b>MENGAPA N-ZIK?</b> Tanpa iklan, pemutaran latar belakang, caching offline, dan UI yang sepenuhnya dapat disesuaikan — gratis, selalu.

🎨 <b>UI yang Dapat Disesuaikan</b>
- Jetpack Compose dengan toggle mode ViMusic Klasik
- Tema: AMOLED, Deep Dark, Crisp Light + aksen warna
- 3D Carousel Player, widget home yang dapat disesuaikan
- Profil artis, News Feed, widget eksperimental

🎵 <b>Pengalaman Audio</b>
- Kualitas premium via YouTube Music Premium 
- Lirik sinkron dengan pengeditan & terjemahan real-time
- Visualisator audio dan kontrol pro: kecepatan, nada, normalisasi, crossfade, peningkatan volume

💾 <b>Offline, Metadata & Privasi</b>
- Caching offline cerdas & unduhan untuk lagu dan daftar putar
- Ekspor FFmpeg dengan metadata lengkap (hanya 64-bit)
- Editor metadata dalam app (AAC/Opus, sampul album)
- Statistik mendengarkan & riwayat 100% lokal
- Cadangan otomatis dengan interval & retensi khusus

🔗 <b>Integrasi</b>
- Login YouTube untuk rekomendasi & peralihan audio/video
- Discord Rich Presence
- Impor/ekspor daftar putar: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Main di Mana Saja:</b> Android Auto, Automotive, TV, dan Tablet

🛠️ <b>Fitur Power User</b>
- Pencarian teks & suara
- Pembaruan OTA dari GitHub
- Timer tidur & pemutaran latar belakang

🛡️ 100% sumber terbuka (FOSS). Izin utama: INTERNET, RECORD_AUDIO (visualisator saja), STORAGE (ekspor/cadangan), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Build yang Tersedia</b>
- Full/Beta: Build lengkap (64-bit)
- Full32/Beta32: Tanpa FFmpeg (32/64-bit)
- Minified: Ringan, untuk perangkat kelas bawah (64-bit)
- Minified32: Ringan tanpa FFmpeg (32/64-bit)
- FOSS: Tanpa auto-updater, untuk F-Droid (64-bit)
- Dev/Dev32: Build pengembangan, hanya untuk pengujian

Build standar 64-bit (FFmpeg); build "32" tanpa FFmpeg untuk kedua arsitektur. Hanya FOSS yang ada di F-Droid.
