Багатомовний фронтенд YouTube Music для Android: продуктивність, вдосконалення UI/UX, розширення функцій, довгострокова підтримка.

<b>N-Zik</b> - відкритий форк <a href="https://github.com/knighthat/Kreate">Kreate</a>.

<b>Примітка:</b> N-Zik розпочався як побічний проєкт. Для більш зрілих рішень зверніть увагу на <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> або <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Використання ШІ:</b> Я використовую генеративний ШІ для коду (через <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD Method</a>), все переглядається та тестується перед випуском.

Звичайний слухач чи аудіофіл - N-Zik дає повний контроль над музикою без компромісів у конфіденційності.

✨ <b>ЧОМУ N-ZIK?</b> Без реклами, фонове відтворення, офлайн-кеш, налаштовуваний інтерфейс - безкоштовно, назавжди.

🎨 <b>Налаштовуваний інтерфейс</b>
- Jetpack Compose, класичний режим ViMusic
- Теми: AMOLED, Deep Dark, Crisp Light + кольорові акценти
- 3D Carousel Player, віджети головної, єдиний плеєр та міні-плеєр
- Профілі виконавців, Discovery та настрої, згортання заголовків головної

🎵 <b>Якість звуку</b>
- Преміум-звук через YouTube Music Premium, автоматично
- Синхронізовані тексти з редагуванням і перекладом у реальному часі
- Розпізнавання музики (як Shazam), голосовий пошук, аудіовізуалізатор
- Професійні налаштування: швидкість, висота тону, нормалізація, кросфейд, посилення гучності, бас-буст, реверберація
- Хвилявий слайдер Audio Bar для точної навігації

💾 <b>Офлайн, метадані та конфіденційність</b>
- Розумне офлайн-кешування та завантаження треків/плейлістів, вибір якості
- Експорт через FFmpeg з повними метаданими (тільки 64-біт)
- Редактор метаданих у додатку (AAC/Opus, обкладинка)
- Локальна статистика та історія прослуховувань
- Авто-бекапи з налаштовуваними інтервалами та тривалістю зберігання

🔗 <b>Інтеграції</b>
- Вхід у YouTube для рекомендацій і відео, плюс експериментальний двосторонній синхронізатор
- Last.fm scrobbling: Now Playing, лайки/скасування лайків
- MusicBrainz: виконавці та альбоми
- Discord Rich Presence; розширений режим із живим переглядом
- Invidious для альтернативного стрімінгу YouTube
- Імпорт/експорт плейлістів: RiPlay, Spotify, YouTube Music, N-Zik

🛠️ <b>Функції для досвідчених користувачів</b>
- Багато профілів: ізольована БД і налаштування на профіль
- Автовідновлення при підключенні Bluetooth, стійка/авто-черга
- Розумний кошик, приховані пісні, система дизлайків, батьківський контроль
- Підтримка проксі, адаптація якості мережі, експорт логів
- Rescue Center, екран обслуговування, початковий курс, швидкі способи додатка
- OTA-оновлення з GitHub, таймер сну, фонове відтворення

🛡️ N-Zik на 100% відкритий (FOSS). Основні дозволи: INTERNET, RECORD_AUDIO (тільки для візуалізатора), STORAGE (експорт/резервні копії), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Доступні збірки</b>
- Full/Beta: Повна збірка (64-біт)
- Full32/Beta32: Без FFmpeg (32/64-біт)
- Minified: Полегшена, для слабких пристроїв (64-біт)
- Minified32: Полегшена без FFmpeg (32/64-біт)
- FOSS: Без автооновлення, для F-Droid (64-біт)
- Dev/Dev32: Збірки для розробників, тільки для тестування

Стандартні збірки - 64-біт (з FFmpeg); "32" прибирають FFmpeg для обох архітектур. У F-Droid лише FOSS.
