<b>N-Zik</b> — ваш багатомовний клієнт YouTube Music для Android з відкритим вихідним кодом.

Форк <a href="https://github.com/knighthat/Kreate">Kreate</a>, зосереджений на продуктивності, вдосконаленні інтерфейсу, виправленні помилок та довгостроковій підтримці.

<b>Примітка:</b> N-Zik розпочався як побічний проєкт. Для більш зрілих рішень зверніть увагу на <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> або <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>Використання ШІ:</b> Я використовую генеративний ШІ для написання коду (через <a href="https://github.com/bmad-code-org/BMAD-METHOD">метод BMAD</a>), все перевіряється та тестується перед випуском.

Незалежно від того, чи ви звичайний слухач, чи аудіофіл, N-Zik дає вам повний контроль над музикою без компромісів у конфіденційності.

✨ <b>ЧОМУ N-ZIK?</b> Жодної реклами, фонове відтворення, офлайн-кеш та повністю настроюваний інтерфейс — безкоштовно, назавжди.

🎨 <b>Настроюваний інтерфейс</b>
- Jetpack Compose з перемикачем класичного режиму ViMusic
- Теми: AMOLED, Deep Dark, Crisp Light + кольорові акценти
- 3D Carousel Player та настроювані віджети на головному екрані
- Профілі виконавців, стрічка новин та експериментальні віджети

🎵 <b>Якість звуку</b>
- Преміум-звук через YouTube Music Premium 
- Синхронізовані тексти пісень із редагуванням та перекладом у реальному часі
- Розпізнавання музики (як Shazam), голосовий пошук та аудіовізуалізатор
- Професійні налаштування: швидкість, висота тону, нормалізація, кросфейд, посилення гучності, бас-буст, реверберація

💾 <b>Офлайн, метадані та конфіденційність</b>
- Розумне офлайн-кешування та завантаження треків і плейлістів
- Експорт через FFmpeg з повними метаданими (тільки 64-біт)
- Редактор метаданих у додатку (AAC/Opus, обкладинка)
- Локальна статистика та історія прослуховувань
- Автоматичне резервне копіювання з настроюваними інтервалами

🔗 <b>Інтеграції</b>
- Вхід у YouTube для рекомендацій та перемикання аудіо/відео
- Інтеграція Invidious для альтернативного YouTube-стрімінгу
- Discord Rich Presence
- Імпорт/експорт плейлістів: RiPlay, Spotify, YouTube Music, N-Zik

📱 <b>Слухайте будь-де:</b> Android Auto, Automotive, TV та планшети

🛠️ <b>Функції для просунутих користувачів</b>
- Автовідновлення при підключенні BT, стійка черга, автозаповнення
- Смітник, приховані пісні, батьківський контроль, шпалери з обкладинки
- Інтеграція Invidious, підтримка проксі, адаптація якості мережі
- OTA-оновлення, таймер сну, фонове відтворення

🛡️ N-Zik на 100% відкритий (FOSS). Основні дозволи: ІНТЕРНЕТ, RECORD_AUDIO (тільки для візуалізатора), ПАМ'ЯТЬ (експорт/бекапи), FOREGROUND_SERVICE, NOTIFICATIONS, REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH, WAKE_LOCK.

📦 <b>Доступні збірки</b>
- Full/Beta: Повна (64-біт)
- Full32/Beta32: Без FFmpeg (32/64-біт)
- Minified: Полегшена для слабких пристроїв (64-біт)
- Minified32: Полегшена без FFmpeg (32/64-біт)
- FOSS: Без автооновлення, для F-Droid (64-біт)
- Dev/Dev32: Збірки для розробників, тільки для тестування

Стандартні збірки 64-бітні (з FFmpeg); у збірках «32» FFmpeg видалено. У F-Droid представлена лише збірка FOSS.
