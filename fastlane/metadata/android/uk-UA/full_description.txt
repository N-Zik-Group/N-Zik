Багатомовний застосунок YouTube Music для Android з акцентом на швидкодію, зручний інтерфейс, нові функції та тривалу підтримку.

<b>N-Zik</b> — форк <a href="https://github.com/knighthat/Kreate">Kreate</a> з відкритим кодом.

<b>Примітка:</b> N-Zik починався як побічний проєкт. Зріліші альтернативи: <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> та <a href="https://github.com/fast4x/RiPlay">RiPlay</a>.

<b>ШІ:</b> Використовую генеративний ШІ для коду за <a href="https://github.com/bmad-code-org/BMAD-METHOD">методом BMAD</a>. Код перевіряю й тестую перед випуском.

✨ <b>ЧОМУ N-ZIK?</b> Без реклами. Фонове відтворення, офлайн-кеш і гнучкий інтерфейс. Завжди безкоштовно.

🎨 <b>Настроюваний інтерфейс</b>
- Компусний інтерфейс Jetpack
- Теми: AMOLED, Deep Dark, Crisp Light + відмічені акценти
- 3D-карусель, віджети, єдиний плеєр і мініплеєр
- Профілі виконавців, відкриття, настрої та згортані заголовки

🫧 <b>Glass (BETA, необов’язково)</b>
У нових інсталяціях вимкнено. У налаштуваннях виберіть для кожної категорії нативний стиль, контури або Glass і задайте якість. Якщо ефект навантажує пристрій або батарею, знизьте якість чи вимкніть його.
Glass: Square / Convx Project (GPL-3.0), Kyant0 AndroidLiquidGlass / Backdrop (Apache-2.0).

🎵 <b>аудіо досвід</b>
- Автоматична якість Premium з YouTube Music Premium
- Синхронізовані тексти з редагуванням і перекладом наживо
- Розпізнавання пісень як у Shazam, голосовий пошук і візуалізатор
- Налаштування: швидкість, висота тону, нормалізація, кросфейд, гучність, бас і реверберація
- Хвильова форма на шкалі для точної навігації

💾 <b>Офлайн, Метадані та Конфіденційність</b>
- Розумне кешування й завантаження треків та плейлистів із вибором якості
- Експорт FFmpeg із повними метаданими (крім x86 32 біти)
- Редактор метаданих додатку (AAC/Opus, обкладинка)
- Локальна статистика та історія прослуховування
- Автоматичні резервні копії з налаштуванням частоти та зберігання

🔗 <b>Інтеграція</b>
- Вхід до YouTube для рекомендацій, відео та експериментальної двосторонньої синхронізації
- Last.fm: скроблінг, поточний трек і вподобання
- Статистика виконавця MusicBrainz і альбому
- Discord Rich Presence, включаючи розширений режим з попереднім переглядом
- Invidious для альтернативного відтворення з YouTube
- Імпорт відтворення/експорт: RiPlay, Spotify, YouTube Music, N-Zik

🛠️ <b>Power User Features</b>
- Мульти-профіль: ізольована база даних і налаштування в профілі
- Автоматичне відновлення при підключенні Bluetooth, постійна черга, автозаповнення
- Розумний кошик, приховані треки, позначки «Не подобається» й батьківський контроль
- Підтримка проксі, адаптація якості, експорт журналу,
- Навігаційний центр, екран обслуговування, ярлики додатків
- OTA оновлення з GitHub, таймера сплячого режиму, фонове відтворення

📦 <b>Доступні збірки</b>
- Release64/Beta64 (`com.nevar.nzik`): Повна збірка для 64-бітних пристроїв
- Release32/Beta32 (`com.nevar.nzik`): Повна збірка для 32-бітних пристроїв
- Minified64 (`com.nevar.nzik`): Збірка легкої ваги, для пристроїв з низьким рівнем покриття (64-розрядна версія)
- Minified32 (`com.nevar.nzik`): Легка збірка R8 (32-bit)
- FOSS (`com.nevar.nzik.foss`): Без автооновлення для F-Droid (всі архітектури)
- Dev64/Dev32 (`com.nevar.nzik.dev`): Збірки для тестування

FFmpeg не входить до збірок. Розширення завантажується при першому використанні й керується в меню Налаштування → Розширення. У F-Droid є лише FOSS.
