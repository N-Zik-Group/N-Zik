Android向けの多言語YouTubeミュージックフロントエンド。パフォーマンス、UI/UX改良、機能拡張、長期サポートに焦点を当てています。

<b>N-Zik</b> は、 <a href="https://github.com/knighthat/Kreate">Kreate</a> のオープンソースフォークです。

<b>注意:</b> N-Zik はサイドプロジェクトとして開始されました。より成熟した選択肢については、 <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a>, または <a href="https://github.com/fast4x/RiPlay">RiPlay</a> をご覧ください。

<b>AI 使用法:</b> 生成AIをコード( <a href="https://github.com/bmad-code-org/BMAD-METHOD">BMAD メソッド</a>を介して)に使用し、出荷前にレビューおよびテストします。

✨ <b>なぜN-ZIK?</b> 広告なし、バックグラウンド再生、オフラインキャッシュ、カスタマイズ可能なUI - 常に無料。

🎨 <b>カスタマイズ可能なUI</b>
- Jetpack Compose Interface
- テーマ：AMOLED、ディープダーク、クリスプライト+色付きのアクセント。
- 3Dカルーセルプレイヤー、ホームウィジェット、ユニファイドプレイヤー、ミニプレーヤー
- アーティストプロフィール、ディスカバリー、気分、折りたたみ式のホームヘッダー

🫧 <b>ガラス効果 (ベータ、オプション)</b>
新規インストール時には無効になります。設定:ネイティブ、輪郭のみ、またはカテゴリ別のガラスを調整可能な品質で有効にします。レンダリング作業とバッテリーの使用を増加させることができます。品質を低下させるか、必要に応じて無効にします。
ガラスクレジット: Square / Convx Project (GPL-3.0); Kyant0 AndroidLiquidGlass / Backdrop (Apache-2.0).

🎵 <b>オーディオエクスペリエンス</b>
- YouTube音楽プレミアムによるプレミアム品質、自動的に適用されます
- 編集とリアルタイムの翻訳と同期された歌詞
- 歌認識（サザムのような）、音声検索、音声ビジュアライザー
- プロコントロール：スピード、ピッチ、正規化、クロスフェード、ボリュームブースト、ベースブースト、リバーブ
- 正確なナビゲーションのためのオーディオバーの波形シークバー

💾 <b>オフライン、メタデータ、プライバシー</b>
- 選択可能なダウンロード品質を持つトラックとプレイリストのスマートキャッシュとダウンロード
- FFmpeg-powered export with full metadata (download on first use; available on 32-bit x86 devices)
- アプリ内メタデータエディタ（AAC/Opus、カバーアート）
- ローカルのリスニング統計と履歴
- カスタムの間隔と保持の自動バックアップ

🔗 <b>統合</b>
- YouTubeにサインインしておすすめとビデオ再生を行い、実験的な双方向同期エンジン
- Last.fm scrobbling with Now Playing and love/unlove
- MusicBrainzアーティストとアルバムの洞察力があります
- ライブプレビューの高度なモードを含むDiscord Rich Presence。
- 代わりのYouTubeストリーミングへの鮮明な統合
- Playlist のインポート/エクスポート: RiPlay, Spotify, YouTube Music, N-Zik

:busts_in_sシルエット: <b>一緒に聞く</b>
- コードまたは招待リンクを介して他のユーザーとライブリスニングセッションに参加またはホスト

🗓️ <b>Rewind</b>
- 自動生成された巻き戻しプレイリストによる年間および月間のリスニング記録

📱 <b>どこでもプレイ可能：</b> Android Auto、自動車、テレビ、タブレット

🛠️ <b>パワーユーザーの機能</b>
- マルチプロファイル: プロファイルごとに分離されたデータベースと設定
- Bluetooth接続、永続キュー、自動入力キュー
- スマートゴミ箱、隠し曲、システムが嫌い、ペアレンタルコントロール
- プロキシサポート、ネットワーク品質の適応、ログのエクスポート
- レスキューセンター、メンテナンス画面、オンボーディング、アプリのショートカット
- GitHubからOTAアップデート、スリープタイマー、バックグラウンド再生

📦 <b>利用可能なビルド</b>
- Release64/Beta64 (`com.nevar.nzik`): 64ビットデバイスのみを完全にビルドする
- Release32/Beta32 (`com.nevar.nzik`): 完全なビルド、32ビットデバイスのみ
- Minified64 (`com.nevar.nzik`): 軽量R8ビルド、ローエンドデバイス (64ビット)
- Minified32 (`com.nevar.nzik`): 軽量R8ビルド (32ビット)
- FOSS (`com.nevar.nzik.foss`): 自動更新なし、F-Droid (すべてのアーキテクチャ)
- Dev64/Dev32 (`com.nevar.nzik.dev`): 開発ビルド、テストのみ

ビルドバンドルなし FFmpeg: ダウンロード可能な拡張機能です (最初の使用時にインストールされ、設定 → 拡張機能で管理されます)。 F-Droidに搭載されているのはFOSSだけです。

過去のプロジェクトのクレジットには、ViMusicが含まれます。
