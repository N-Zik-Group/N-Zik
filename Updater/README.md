# N-Zik version codes

Android version codes are whole numbers. The Theme Store uses them to check whether an installed version can apply a theme.

- **Your installed version** appears in the theme editor, next to its Android version code.
- **The current source version** is listed under `nzikVersionName` and `nzikVersionCode` in the [version catalog](../gradle/libs.versions.toml#L23-L24).
- **The latest stable release** is listed on the [GitHub releases page](https://github.com/N-Zik-Group/N-Zik/releases/latest).
- **All updater changelogs** are in the [changelog directory](changelogs/). The number in each filename is the Android version code.

## Theme compatibility

The Theme Store is in beta and requires **N-Zik 8.7.0 or later (Android version code 97)**. A theme can require a higher version when it uses a newer feature.
